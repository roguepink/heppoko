# 勇者へっぽこの小さな冒険 — 企画の土台(ノブさんの要望の整理)

## ひとことで
「隣町に大魔王が現れた。勇者にあこがれる **お金持ちの子・へっぽこ** が、**お金の力** で武器・防具をそろえ、**10組の仲間** を集めて、**たった一度の大決戦** に行く」小さな RPG。
- 舞台は **最初の町ひとつだけ**。町の中で全部が完結する(世界に残る大きな物語を、町ひとつで)。
- 戦いは **最強のボス(大魔王)と1回だけ**。そこに全力。すごくスリリング、桁外れ、笑える。
- すぐ終われるが、こだわればこだわるほど時間がかかる(集め・そろえの楽しさ)。
- 遊び心と視野の広さ。ドラクエっぽさは **25%** まで、あとはバラエティ豊かに。
- 対象: スマホで遊ぶ日本の一般の人(子どもから年配まで)。字は大きめ、操作はやさしく。

## 絶対に入れる要素
1. **装備**: へっぽこ **だけ** が装備できる。できるだけ多くの部位(右手・左手・頭・顔・体・マント・腰・足・指輪・お守り など)。たくさんの種類(武器・防具 合わせて **80 以上**)。笑える・豊か。装備した物は **攻撃コマンドとして使える**(防具でも「フライパンで殴る」など)。
2. **装備したら大画面で見た目が出る**(かわいい確認画面)。へっぽこの全身に装備が反映される。
3. **仲間 10 組まで**。「組」= 1人でも 700人でも1組。例: 戦士1人 / 魔法使い1人 / 僧侶1人 / 本当の遊び人 / 小人700人の群れ / 大魔王にこき使われていたモンスターたち / **隣の家のおばさんが一番強い** / など、思いつく限りバラエティ豊かに(**30 組以上**用意し、その中から10組選ぶ)。
4. **仲間の誘い方いろいろ**: 大金を払う / お金はいらないがちょっとしたお願いを聞く(小さなイベント・おつかい) / 出会うだけ / なぞなぞ / など。仲間の装備は変えられない。戦闘では自動で 攻撃・守り・回復(スマホで回復する子もいる)などをしてくれる。
5. **町**: 王様(すごくいい加減)、やさしい町の人、ペットのモンスター(かわいい)、店いろいろ。ドラクエ風の見下ろし歩きで、仲間 10 組が後ろに **連なって** 歩く。
6. **ボス戦のコマンド**: 「たたかう」のほかに **無駄コマンドをたくさん**(謝る・逃げたい・攻撃するふり・泣く・自慢する・お金を見せる・ほめる・寝る・など 20 以上)。それが **なんだかんだで最強** だったりする仕掛け(ボスの状態と組み合わさって大ダメージ、など)。
7. **ギリギリで勝てる調整**: 装備と仲間を揃えると、ちょうどギリギリ勝てる。すごくスリリング。
8. **勝ったら最高の決めポーズで記念写真**。自分で組んだ装備と仲間たちと一緒にポーズ → スクショ/保存できる場面。
9. 負けても大丈夫(町に戻ってやり直し。お金持ちなので…)。

## 技術の決まり(変えない)
- スマホ縦向き・1ページの PWA。HTML/CSS/JS だけ、ライブラリ・CDN・画像ファイルなし。絵は **絵文字と図形**、音は WebAudio で作る。
- ファイルは index.html + js/*.js(data.js にデータ、ほかにロジック)。ES modules は使わない。
- 保存は localStorage(途中セーブ)。
- 文章はすべて日本語、やさしい言葉。字は大きめ。
