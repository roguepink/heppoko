## 0. ひとことで(設計の芯)

- 大魔王の HP は **999,999**。パーティの通常攻撃は 1発 3,000〜15,000。ふつうに殴るだけだと **17〜18ターン**かかり、その前に大魔王の攻撃でへっぽこが倒れる。
- 勝ちの鍵は **「大魔王の気分」を読んで、無駄コマンドで「心のダメージ」(HP の 6〜15%)を当てる**こと。これで 12〜16 ターンに縮まり、ギリギリ勝てる。
- 大魔王は **4 フェーズ**(100→70→40→15%)で強くなり、**予告つきの大技**で全滅のスリルを作る。guard 役の仲間と「まもる」で受け止める。
- 最強寄りの装備(約 620万G)+ 仲間10組(約 335万G)= 約 955万G で、**勝率 68%**(ヒントに気づく確率 70% のふつうの人)。装備が中くらいだと 20%、仲間 6 組だと 20%。

## 1. ターン制の流れ(1ターン = 10〜20 秒)

```
[ターン開始]
  ① 大魔王の様子(気分)とヒントが画面に出ている(前のターンの終わりに出たもの)
  ② へっぽこのコマンドを選ぶ(待ち。ここだけプレイヤーの操作)
       たたかう ▶ 装備している物のリスト(最大10個) → 1つ選ぶ
       まもる
       むだ   ▶ 22 個の無駄コマンドの一覧(3列 × 8行、スクロール無し・字は大きめ)
  ③ へっぽこの行動を表示(1.2 秒)
  ④ 仲間 10 組が上から順に自動で行動(1組 0.5 秒 → 約 5 秒。画面タップで 3 倍速)
       順番: support → guard → heal → attack → weird(バフと守りを先に、変なのは最後)
  ⑤ 大魔王の行動(2 秒。大技は 3 秒)
  ⑥ 大魔王の気分が変わる/フェーズが変わる → セリフとヒントを表示(1.5 秒)
  ⑦ 勝ち負けの判定 → 次のターンへ
```

- 操作は **1本指・タップだけ**。スワイプもドラッグも使わない。ボタンは最低 56px 四方。
- 1ターンの自動部分は約 10 秒、プレイヤーの考える時間を入れて 10〜20 秒。1戦 12〜18 ターン = **3〜6 分**。
- 「素早さ」は行動順には使わない(順番は上の固定)。素早さは **大魔王の単体攻撃を避ける確率**(§2)に使う。ターン制の順番が毎回変わるとスマホで読みにくいため。
- 「連打で飛ばす」: ④ の途中でタップすると残りの仲間の行動を 3 倍速で流す。ただし **大技・コンボ・倒れた** の表示は飛ばせない(見逃し防止)。

## 2. へっぽこの数値(装備の合計だけで決まる・レベル無し)

### 2-2. 部位ごとの「強」装備の目安(10 部位)

- 「強」でも 1 個だけ飛び抜けた物(例: 伝説の剣 atk 130・999,999G)があってよい。ただし合計 atk が 380 を超えないように値段で調整。
- **笑える装備は威力を少し高く**(フライパン・まないた・たらい など)。笑いの導線として「防具で殴るほうが強い」部位があってよい。
- 装備の `extra.heal` がある物は、「たたかう」で選ぶと攻撃ではなく **へっぽこ回復**(回復量 = heal × 10)になる。type:'heal'。

### 2-3. へっぽこの攻撃の式

```
ダメージ = power × (atk合計 × 20 + 200) × ゆらぎ(0.9〜1.1) × クリティカル × 大魔王の受けやすさ × 仲間のバフ
クリティカル: 確率 = min(30%, luck ÷ 100)、当たると ×2.0
大魔王の受けやすさ: 気分による(§3-4。自慢 0.7 / 怒り 1.1 / 油断 2.0 / 眠っている 1.5 / ほかは 1.0)
仲間のバフ: support の「こうげきの歌」で ×1.25(そのターンのみ。へっぽこは次のターン)
```

例: 強装備(atk 353)で power 1.8 の剣 → 1.8 × (7,060 + 200) ≒ **13,000**(クリティカルで 26,000)。
中装備(atk 163)power 1.5 → **5,200**。弱装備(atk 48)power 1.2 → **1,400**。

### 2-4. へっぽこが受けるダメージ・避ける確率

```
受けるダメージ = 大魔王の攻撃の元の値 × フェーズ倍率 × 気分の攻撃倍率 × ゆらぎ(0.9〜1.1) × 100 ÷ (100 + def合計)
「まもる」をしたターン: さらに ×0.3
避ける: 単体攻撃だけ、確率 = min(25%, spd ÷ 200)。全体攻撃と大技は避けられない。
```

例: 強装備 def 222 → ×0.31。第1フェーズの通常攻撃 900 → **約 280**(HP 1,300 の 1/5)。第4フェーズ(×2.0)→ 560。
大技 2,000 × 2.0 × 0.31 = 1,240 → まもらないと 1 発で倒れる水準。まもる(×0.3)で 372、guard の仲間がいれば ×0.2 → 75。

### 2-5. お金の目安(所持金 1,000万G)

| 使い道 | 値段帯 | 全部そろえると |
|---|---|---|
| 装備「弱」(店の入口の棚) | 1,000〜30,000 | 約 12万 |
| 装備「中」(奥の棚) | 50,000〜300,000 | 約 180万 |
| 装備「強」(ショーケース) | 400,000〜900,000(1 個だけ 999,999 可) | 約 620万 |
| 仲間(お金で誘う pay) | 300,000〜800,000 / 1組 | 強い 6〜7 組で約 335万 |
| 仲間(お願い favor / おつかい quest / なぞなぞ riddle / 出会うだけ free) | 0G(時間がかかる) | 3〜4 組 |
| **最強寄りの全部** | | **約 955万**(残り 45万) |

- 一番強い仲間「隣の家のおばさん」は **0G(お願いを聞く)**。「お金で全部は買えない」のメッセージ。
- お金は足りるが、**全部そろえると残りが少ない**ように作る。1,000万をちょっと超える構成(強を全部 + 全員 pay)は組めない → 何を削るか悩む楽しさ。

## 3. 大魔王

### 3-1. 基本

| 項目 | 値 |
|---|---|
| 名前(案) | 大魔王 ズボラルドス(王様の命名。いい加減) |
| HP | **999,999**(表示もこの桁。減るとき数字がカラカラ回る) |
| 守り | 0(気分で「受けやすさ」が変わるだけ) |
| 通常攻撃(1人に) | 元の値 **900** × フェーズ倍率 |
| 全体攻撃(全員に) | 元の値 **450** × フェーズ倍率 |
| 大技(予告→次のターン、全員に) | 元の値 **2,000** × フェーズ倍率 |
| 回復 | 最大 HP の **8%**(第3フェーズのみ、戦闘中 2 回まで) |
| 単体攻撃のねらい | へっぽこ 35% / 残りの 65% を生きている仲間で均等 |

### 3-2. フェーズ(HP 割合で変わる)

| フェーズ | HP | 攻撃倍率 | 行動の重み(通常/全体/大技予告/回復/気分だけ) | 大技の間隔 | 攻撃後に気分が変わる確率 | 出る気分 | 入ったときのセリフ・演出 |
|---|---|---|---|---|---|---|---|
| 1 よゆう | 100〜70% | ×1.0 | 45 / 20 / **0** / 0 / 35 | なし | 60% | 自慢・挑発・笑い・眠い | 「ほう、お金持ちのボウヤか。遊んでやろう」 |
| 2 いらいら | 70〜40% | ×1.2 | 35 / 25 / 20 / 0 / 20 | 3ターン以上あける | 50% | 怒り・自慢・眠い・挑発・おなかすいた | 気分が**怒り**になって始まる。「調子にのるな!」画面ゆれ(中) |
| 3 あせり | 40〜15% | ×1.5 | 30 / 25 / 25 / 10 / 10 | 3ターン以上あける | 50% | 泣く・おなかすいた・さびしい・怒り・笑い | 気分が**泣く**になって始まる。「なんでじゃー!」HP バーがオレンジ |
| 4 ほんき | 15〜0% | ×2.0 | 25 / 35 / 40 / 0 / 0 | 2ターン以上あける | 30% | 怒りだけ | **入ったとたんに大技の予告**。画面が暗くなり「本気を出す」。HP バー赤・BGM 速く |

- 「気分だけ」の行動 = 大魔王はそのターン攻撃せず、気分を出す(例: ツノをみがいて自慢)。第1フェーズで多いのは、**コンボを覚える練習時間**にするため。
- フェーズが変わる瞬間に「ためる」中なら、気分の上書きはしない(予告した大技は必ず出す)。
- 第4フェーズ入りの大技予告は「1ターン前の予告 → 次のターン発動」の形は同じ。プレイヤーはコマンド前に予告を見られる。

### 3-3. 大魔王の 1 ターンの決め方(順番)

```
1. 気分が「眠っている」「動揺」なら → 何もしない(セリフだけ)。気分の残りターンを 1 減らす
2. 気分の「ぼんやり確率」(眠い 40%・笑い 30%)に当たったら → 何もしない
3. 気分が「ためる」なら → 大技を発動(全員に 2,000 × 倍率)。気分はふつうに戻る
4. それ以外 → フェーズの重みで 通常 / 全体 / 大技予告 / 回復 / 気分だけ を選ぶ
     - 大技予告は「前の予告から 間隔ターン 未満」なら選べない
     - 回復は残り回数 0 なら選べない
5. 攻撃したあと、気分が「ふつう」なら、フェーズの確率で新しい気分になる(そのフェーズの一覧からランダム)
   気分があるときは残りターンを 1 減らし、0 でふつうに戻る
```

## 4. 無駄コマンド(22 個)と「気分 × コマンド」の表

### 4-1. 効果の書き方(プログラムの約束)

| 効果コード | 意味 |
|---|---|
| `dmg N` | 心のダメージ。大魔王の **最大 HP の N%**(気分の「受けやすさ」は掛けない。固定) |
| `clear` | 気分をふつうに戻す |
| `mood X` | 気分を X にする |
| `skip` | 大魔王が次の行動を 1 回とばす(動揺 1 ターン) |
| `batk k,n` | 大魔王の攻撃 ×k が n ターン続く |
| `bdef` | 大魔王の受けるダメージ ×1.3 が 1 ターン(守りがくずれる) |
| `hheal N` / `pheal N` | へっぽこ / 全員 の HP を最大の N% 回復 |
| `bheal N` | 大魔王が N% 回復(逆効果・笑いどころ) |
| `self N` | へっぽこが最大 HP の N% ダメージ |
| `buff k` | 次のターン 仲間とへっぽこの攻撃 ×k |
| `hguard` | 大技に対して へっぽこの受けるダメージ ×0(逃げ腰でかわす) |
| `—` | 何も起きない(セリフだけ・笑える) |

**同じ気分に同じコマンドを 2 回目以降に使ったとき**: `dmg` は 1/4 になる(気分の変化は起きる)。連打で勝てないようにするため。

## 5. 仲間の役割と自動行動

### 5-1. 仲間のデータ(brief の `battle` に `def` を足す)

```js
battle: { hp: 1500, def: 30, role:'attack', power: 70, count: 1,
          lines:['…'], special:{ name:'…', text:'…', effect:'…' } }
```

- **数の力(count ≥ 2 の組)**: HP は組の合計。HP が減ると人数の表示も減る(`表示人数 = ceil(count × hp ÷ maxHp)`。「小人 700 人 → 523 人」)。
  攻撃力は `× (0.5 + 0.5 × hp ÷ maxHp)`(人が減ると弱くなる)。1 人の組はこの補正なし。
- 攻撃の式: `power × 115 × ゆらぎ(0.85〜1.15) × 数の力 × 役割の倍率 × 大魔王の受けやすさ × バフ`
- 受けるダメージ: へっぽこと同じ式(`× 100 ÷ (100 + def)`)。避けはしない。
- HP 0 で「たおれる」(人数の組は「にげた」)。heal 役が 1 戦に 1 回だけ呼び戻せる(HP 半分で復帰)。

### 5-2. 役割ごとの行動のアルゴリズム

| 役割 | 判断の順番(上から当てはまったものを 1 つ) | 攻撃の倍率 |
|---|---|---|
| **attack** | 毎ターン攻撃 | ×1.0 |
| **guard** | ① 大魔王が「ためる」→ **まもりの構え**(そのターンの大技を 全員 ×0.2。guard 2 組なら ×0.1)② それ以外 → 攻撃 | ×0.6 |
| **heal** | ① へっぽこの HP < 60% → へっぽこを回復(power × 12)② 倒れた仲間がいて 呼び戻し残り 1 → 呼び戻す ③ 誰かの HP < 50% → 一番低い人を回復(power × 12)④ 攻撃 | ×0.4 |
| **support** | ターン番号 % 3 で回る: 0 → **こうげきの歌**(このターンの仲間の攻撃 ×1.25。へっぽこは次ターン)/ 1 → **まもりの旗**(次の大魔王の攻撃を全員 ×0.75)/ 2 → 攻撃。さらに毎ターン **気分のヒント(レベル2)を言う** | ×0.6 |
| **weird** | 毎ターン サイコロ: 15% なぜか大当たり(×3.0)/ 15% みんな元気(全員 20% 回復)/ 25% 昼寝(何もしない)/ 15% 大魔王の気分をランダムに変える(ためる・油断・眠っている中は不発)/ 10% 自分でころぶ(自分に 20%)/ 10% 大魔王を笑わせる(mood 笑い)/ 10% まちがえて大魔王を回復(1%) | — |

- 気分を変える weird は、**コンボの機会を増やす**役。遊び人がいると勝率が上がる(数字上も)。
- 10 組の中の役割の目安(お金で買える最強寄り): attack 4・guard 2・heal 2・support 1・weird 1。全部 attack にすると大技で全滅、全部 guard にすると火力不足。**選び方で勝率が動く**のが狙い。

### 8-3. UI 側(battle-ui.js)がやること

- `runTurn` の `events` を **キューに入れて順に再生**(各 type に表示時間を持たせる。text 1.0 秒・damage 0.5 秒・combo 1.5 秒・big 3 秒・phase 1.5 秒・end 2 秒)。タップで 3 倍速、ただし big/combo/down/phase/end は等速。
- 再生中はコマンドボタンを押せない。再生が終わったら `hintFor(state)` を出してコマンド待ち。
- 1 ターン終わるごとに `state` を localStorage に保存(`heppoko.battle`)。途中で閉じても同じターンから再開。
- 戦闘が終わったら `discovered` を `heppoko.discovered` に合流して保存。

## 9. 実装者への注意 10 個

1. **ロジックと表示を完全に分ける。** `js/battle.js` は DOM をさわらない・`setTimeout` を使わない・乱数は引数の `rng` だけ。こうしておくと `simulate()` で何千回も回せて、Python の表と突き合わせられる。
2. **定数は 1 か所に。** `DMG_SCALE_HERO=20`・`DMG_SCALE_COMP=115`・`BOSS.atk`・コンボの % を `BATTLE.CONST` にまとめ、sim_battle.py の値と**同じ名前・同じ数**にする。片方を変えたらもう片方も変える(この文書の §6 の表も)。
3. **勝ち判定は「大魔王 HP ≤ 0」を先に見る。** 同じターンでへっぽこも 0 になることはない(大魔王が倒れたら大魔王の行動はない)が、順番を間違えると「勝ったのに負け」が出る。
4. **大技は必ず「予告 → 次のターン発動」。** フェーズ変化で気分を上書きするとき、`charge` は上書きしない(sim で一度バグった箇所)。予告の表示は飛ばせない(3 倍速の対象外)。
5. **コンボの 心のダメージは「最大 HP の %」で固定。** 気分の受けやすさ(自慢 0.7 など)は掛けない。同じ気分 × 同じコマンドは 2 回目から 1/4(`comboUsed` を数える)。
6. **ママを呼ぶは 1 戦 1 回。** ボタンは使ったらグレーにして「もう来ない」と書く。
7. **数の力の組(count ≥ 2)**は HP を組の合計で持つ。表示人数は `ceil(count × hp / maxHp)`、攻撃は `× (0.5 + 0.5 × hp/maxHp)`。倒れたときの文は「たおれた」でなく「にげだした」。
8. **ヒントは 3 段階を必ず全部つける。** 特に「ためる」の予告で「まもる」ボタンが光ること、support 役がいれば毎ターンつぶやくこと。テストでは「初見の人(うまさ 0.35)が 10 組・強装備で 50% 前後勝てる」を目標にする。
9. **数字の表示は常にカンマ区切り**(`toLocaleString('ja-JP')`)。大魔王の HP の減りは 0.6 秒のアニメで目標値へ(途中で次のダメージが来たら、現在の表示値からやり直す)。字は 18px 以上、ダメージは 28px 以上。
10. **途中保存は毎ターン。** `state` 丸ごとを `localStorage['heppoko.battle']` に。再開時は演出なしでコマンド待ちから。戦闘が終わったら消す。`discovered` だけは別キーで残す(負けても消えない。これが次の挑戦の武器になる)。

## 付録: 数字の根拠メモ

- 1 ターンのパーティの通常火力(強 + 10 組、バフなし): へっぽこ 13,000 + attack 4 組 ≒ 27,000 + guard 2 組 ≒ 6,000 + heal 2 組(回復していないとき)≒ 3,500 + support ≒ 2,000(1/3 の確率)+ weird 平均 ≒ 4,000 → **約 55,000 / ターン** → 999,999 ÷ 55,000 ≒ 18 ターン。
- コンボで 1 戦に平均 3〜4 回・合計 35〜45%(約 400,000)入ると → 600,000 ÷ 55,000 ≒ 11 ターン + 予告・気分だけのターン ≒ **13〜16 ターン**。
- へっぽこが受ける合計(強装備・16 ターン): 単体 ×5〜6 回(280〜560)+ 全体 ×4 回(140〜280)+ 大技 ×3 回(まもって 75〜370)≒ **3,000〜3,500** vs HP 1,300 + heal 2 組の回復(1 回 420 × 5〜6 回 ≒ 2,300)+ ママ 1,300 → ほぼ釣り合う = ギリギリ。heal 役が倒れると崩れる。

## 実装後の調整メモ(2026-10-29・JS の simulate で測り直し)
- 第4フェーズに入った瞬間の「ためる」は、その同じターンに大技を出さず「ふるえながら 力を ためている」で1ターン待つ(予告→次のターンの約束を守る)。これで勝率が大きく上がったため、下の値に調整した。
- 定数(js/battle.js の CONST): DMG_SCALE_COMP=70(data.js の仲間の power が 25〜120 と大きいため)、BOSS_ATK single=1,000 / all=450 / big=2,600、HERO_TARGET_P=0.5、第4フェーズ倍率 3.0、chargeGap 2。
- 結果(各 600 回): 強装備+役割バランスの10組 = 初見 61% / ふつう 73% / 達人 81%。2番手の10組 19%、中装備+10組 7%、強装備+6組 28%、弱装備 0%。
