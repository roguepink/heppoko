# 勇者へっぽこの小さな冒険

隣町に大魔王が現れた! 勇者にあこがれる お金持ちの子・へっぽこが、**お金の力** で武器と防具をそろえ、町じゅうから **仲間を10組** 集めて、**たった一度の大決戦** へ。
笑えて 熱い、スマホ縦向きの小さなRPG。1ファイルの PWA(ホーム画面に入れられ、電波がなくても動く)。

- 遊ぶ: https://roguepink.github.io/heppoko/
- 装備 100 種類以上(フライパン・こたつ・金のうんち…)。へっぽこだけが装備でき、装備した物は攻撃に使える。装備すると大画面でお披露目。
- 仲間 30 組以上から 10 組(戦士・魔法使い・小人700人・元手下のモンスター・隣の家のおばさん…)。誘い方はお金・お願い・なぞなぞなど。
- ボス戦は一度きり。「あやまる」「ほめる」「おにぎりをあげる」などの無駄コマンドが、大魔王の気分しだいで最強の一手に。
- 勝ったら決めポーズで記念写真(保存・共有できる)。

## 作り
- `index.html` + `js/*.js`。ライブラリ・CDN・画像ファイルなし(絵は絵文字と図形、音は WebAudio)。
- `js/data.js` 中身のデータ / `js/battle.js` 戦闘の計算(純粋な関数。`BATTLE.simulate` で自動対戦) / `js/doll.js` 着せ替え人形 / `js/town.js` 町 / `js/menu.js` 店・装備・仲間 / `js/battle-ui.js` ボス戦の画面 / `js/photo.js` 記念写真 / `js/main.js` 全体の流れ。
- 設計書は `docs/`(brief・design-ui・design-battle・interfaces)。
